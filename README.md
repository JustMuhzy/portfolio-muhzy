# Muhzy — Personal Portfolio

Static personal portfolio built with HTML, CSS and vanilla JavaScript. No database or backend required.

## Run locally
Simply open `index.html` in your browser, or use VS Code Live Server.

## Deploy to GitHub + Vercel
1. Create a GitHub repository (for example `portfolio-muhzy`).
2. Upload the project files and folders.
3. Sign in to Vercel using GitHub.
4. Select **Add New → Project** and import the repository.
5. For a static site, leave the framework preset as **Other** (or None), with no build command and no output directory required.
6. Deploy.

Vercel will deploy updates automatically whenever changes are pushed to the connected GitHub repository.

## Personalize before publishing
- Replace `your.email@example.com` in `index.html` with your email.
- Update the GitHub link to your own profile URL.
- Add your profile photo or project screenshots inside `assets/images/` and update the page as desired.
- Review the project descriptions and skill list to match your experience.

## Project structure
- `index.html` — portfolio content
- `assets/css/style.css` — design and responsive styling
- `assets/js/script.js` — menu, active navigation and scroll reveal
- `vercel.json` — simple static deployment configuration
